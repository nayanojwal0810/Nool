# Data Classification Standard

Lindenmere Services
Document ID: IT-006
Owner: Information Technology
Version: 1
Effective date: 2026-01-01
Audience: All employees

## Purpose and scope

Employees need common labels before sharing company information.

## Policy

Use Public, Internal, Confidential, or Restricted labels. Personnel records, customer contracts, and access credentials are Restricted unless a data owner assigns a stricter rule.

## Procedure

Choose the label when creating a file, check the recipient list before sharing, and use an approved storage location for the label.

## Responsibilities and follow-up

Restricted files may be shared only through an approved channel with an authorized recipient. If a file is sent to the wrong person, report it as an incident.

## Example

A customer contract labeled Restricted stays in approved storage. The employee checks recipient access before sharing and reports an accidental share promptly.

## Exceptions

Ask the data owner or security desk when a label is unclear; do not downgrade a label to make sharing easier.
