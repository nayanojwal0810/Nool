# Backup and Restore Guide

Lindenmere Services
Document ID: IT-008
Owner: Information Technology
Version: 1
Effective date: 2026-01-01
Audience: All employees

## Purpose and scope

Staff need to know which work is backed up and how to request recovery.

## Policy

Save work in approved cloud drives or managed repositories. Local desktop files are not covered by the standard backup service.

## Procedure

Move working files to an approved location and verify sync status. Open a service desk ticket with the file location and last known good date for a restore request.

## Responsibilities and follow-up

The service desk confirms what can be restored and the likely recovery date. Employees should not overwrite the affected location while a restore is in progress.

## Example

An employee who deleted a shared file submits its location and last good date. IT checks the managed backup and confirms whether a restore is possible.

## Exceptions

IT cannot promise recovery for files stored only on an unbacked local drive.
