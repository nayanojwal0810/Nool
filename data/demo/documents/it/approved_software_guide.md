# Approved Software Guide

Lindenmere Services
Document ID: IT-007
Owner: Information Technology
Version: 1
Effective date: 2026-01-01
Audience: All employees

## Purpose and scope

Software installation needs a review of security, cost, and support.

## Policy

Employees may install software from the managed catalog. Other software needs service desk review and purchasing approval before installation or payment.

## Procedure

Search the catalog first. If a tool is missing, submit its name, purpose, vendor, and data it will handle through the service desk.

## Responsibilities and follow-up

IT records the review result and supported version before adding software to the catalog. Employees must not use a personal subscription to bypass a rejected request.

## Example

A team wants a new design tool that is not in the catalog. It sends the vendor and data-use details for review before purchasing a license.

## Exceptions

IT may block an urgent request until security review is complete, even if the manager approved its cost.
